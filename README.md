# kindle-display
Ảnh màn hình để bàn: `kindle.png` (Kindle 1072x1448), `phone.png` (Android 1080x2400).
Cập nhật tự động bởi tác vụ theo lịch của Claude. `render.py` đọc `data.json` và vẽ ảnh; `make_phone.py` tạo bản điện thoại.
Repo công khai: không ghi tên khách, số tiền hay hợp đồng vào data.json.
